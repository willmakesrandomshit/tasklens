# Security policy

TaskLens interacts with operating-system processes and should be treated with care. Do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled on the repository; otherwise contact a maintainer privately through a verified GitHub profile and share details only through an agreed private channel.

Include affected version or commit, reproduction steps using disposable processes, impact, and any suggested mitigation. Do not include credentials or other people's private information. Supported versions and response timelines will be documented once releases and a security contact are established.
